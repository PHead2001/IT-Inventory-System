Set `AUTH_DIAGNOSTICS=1` only on a local loopback database or an isolated Vercel preview. Production disables the observer. Each `AUTH_DIAGNOSTIC` log event contains only a random per-request correlation ID, one fixed stage name and elapsed milliseconds. `login.credentials` is an inclusive SDK call spanning provider response parsing and session subscriber work; `cookie.setAll` can be nested within it. These spans cannot be added or subtracted as independent stages. `member.*` belongs to a separate protected request and retains fresh Auth and membership checks.
